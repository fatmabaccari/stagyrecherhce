# 🎯 StagYRecherche — Page de recherche d’entreprise

**StagYRecherche** est une application web collaborative dédiée à aider les étudiants à trouver des stages, en s’appuyant sur les expériences partagées par d’anciens stagiaires.  
Ce dépôt contient **la page de recherche d'entreprise**, développée dans le cadre d’un **projet de groupe** universitaire.

---

## 🔍 Objectif

Faciliter l’accès à des informations fiables sur les entreprises qui accueillent des stagiaires, grâce aux avis et retours d’expérience des étudiants.

---

## 🛠️ Fonctionnalités

- Recherche d’entreprises par nom
- Filtres (secteur, localisation, notation, etc.)
- Affichage des témoignages d’anciens stagiaires
- Évaluation moyenne des entreprises

---

## 🤝 Travail d’équipe

Ce projet a été réalisé en collaboration avec plusieurs membres du groupe.
